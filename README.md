# Data Manipulation with Python

This repository contains my Data Manipulation assignment using Python in Google Colab.  
The project focuses on exploring, cleaning, transforming, and analyzing data using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Dataset used:
- supermarket_sales.csv

## Topics Covered
- Data Loading
- Data Cleaning
- Data Type Conversion
- Sorting & Filtering
- GroupBy Analysis
- Pivot Table
- Crosstab
- Merge & Append
- Datetime Analysis
- Standard Scaling
- MinMax Scaling
- Data Visualization

## Visualization Techniques
- Histogram
- Boxplot
- Scatterplot
- Line Chart
- Area Plot
- FacetGrid

## Insights
Some analyses performed in this project include:
- Identifying products with the highest sales
- Analyzing gross income across cities
- Understanding customer spending patterns
- Exploring relationships between total bill and tip
- Comparing subgroup distributions using FacetGrid

## Purpose
This project was created as part of my learning journey in Data Analytics and Python Data Manipulation.
